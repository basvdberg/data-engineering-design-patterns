# Design patterns index

This page provides a quick way to browse all design patterns in this folder.

## Patterns

| Pattern | Description |
| --- | --- |
| [Event-based orchestration](./event%20based%20orchestration.md) | Defines an event-driven orchestration model where events trigger tasks that are queued and executed with centralized control. |
| [Object property tree](./Object%20property%20tree.md) | Models data objects in a hierarchy with inheritable properties, contracts, and schema metadata for configurable processing. |
| [Historic bitemporal table](./Historic%20bitemporal%20table.md) | Stores historical versions with valid-time intervals and recording timestamps to support auditing and point-in-time analysis. |

## How to use this index

- Start with event orchestration for process flow and task execution.
- Use object property tree for metadata-driven object and configuration management.
- Use historic bitemporal table when data must keep full temporal history.
