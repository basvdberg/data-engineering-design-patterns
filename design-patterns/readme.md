## Patterns

| Pattern | Description |
| --- | --- |
| [Event-based orchestration](./event-based-orchestration.md) | Defines an event-driven orchestration model where events trigger tasks that are queued and executed with centralized control. |
| [Object property tree](./object-property-tree.md) | Models hierarchical data objects with inheritable and overridable properties for flexible metadata-driven processing. |
| [Historic bitemporal table](./historic-bitemporal-table.md) | Stores historical versions with valid-time intervals and recording timestamps to support auditing and point-in-time analysis. |

## How to use this index

- Start with event orchestration for process flow and task execution.
- Use object property tree for metadata-driven object and configuration management.
- Use historic bitemporal table when data must keep full temporal history.
