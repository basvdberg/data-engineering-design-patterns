# Purpose

Design patterns describes functionality in a descriptive technology agnostic way. The main reasons for doing this is:

- It gives you a vocabulary to discuss frameworks, tools, platforms and data solutions. Using this you can compare them. 
- It can be used as a blueprint for AI generation of the underlying code. You can select the patterns that you need for your use case.
